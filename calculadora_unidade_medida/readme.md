# 📏 Calculadora de Unidades de Medidas

Uma aplicação desktop simples e intuitiva desenvolvida em Python e Tkinter para conversão de diversas unidades de medidas físicas e matemáticas.

---

## 🚀 Funcionalidades

- **Conversão Multicategoria:** Suporte para 9 categorias de medidas:
  - ⚖️ **Massa:** kg, hg, dag, g, dg, cg, mg
  - ⏱️ **Tempo:** ano, mês, semana, dia, h, min, s, ms
  - 📐 **Comprimento:** km, hm, dam, m, dm, cm, mm
  - 🗺️ **Área:** km², hm², dam², m², dm², cm², mm²
  - 🧪 **Quantidade/Volume:** m³, l, dl, cl, ml
  - 🚗 **Velocidade:** km/h, m/s, mph, nó
  - 🌡️ **Temperatura:** Celsius (°C), Fahrenheit (°F), Kelvin (K)
  - ⚡ **Energia:** kJ, J, kcal, cal, kWh, eV
  - 🎈 **Pressão:** bar, atm, Pa, kPa, mmHg, psi
- **Interface Gráfica Amigável:** Design moderno com ícones interativos e seleções rápidas via Combobox.
- **Formatação Inteligente:** Exibição dinâmica de resultados (suporta notação científica para números muito pequenos).

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Tkinter** (Interface gráfica padrão do Python)
- **Pillow (PIL)** (Processamento e manipulação de imagens/ícones)
