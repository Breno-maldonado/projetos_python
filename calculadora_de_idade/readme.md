# ⏳ Calculadora de Idade em Python

Uma aplicação desktop simples e intuitiva desenvolvida em **Python** utilizando **Tkinter** para a interface gráfica. O aplicativo calcula a diferença exata de idade entre duas datas, exibindo o resultado detalhado em **anos**, **meses** e **dias**.

---

## 🎨 Funcionalidades

- **Cálculo Preciso:** Calcula a diferença entre a data atual (ou qualquer data inicial) e a data de nascimento.
- **Seleção Dinâmica de Datas:** Utiliza um calendário interativo (`tkcalendar`) para facilitar a escolha de datas.
- **Interface Dark Mode:** Design elegante em estilo dark/moderno.
- **Detalhamento Completo:** Retorna a idade exata separada por anos, meses e dias decorridos.

---

## 🛠️ Tecnologias Utilizadas

- **[Python 3]** Linguagem principal do projeto.
- **[Tkinter]** Biblioteca padrão do Python para criação da interface gráfica (GUI).
- **[tkcalendar]** Widget de calendário e seletor de datas para Tkinter.
- **[python-dateutil]** Biblioteca para manipulação avançada de datas e cálculo de relatividade (`relativedelta`).
