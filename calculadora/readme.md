# 🧮 Calculadora em Python (Tkinter)

Uma aplicação desktop de calculadora funcional e estilizada, desenvolvida em Python utilizando a biblioteca gráfica **Tkinter**.

---

## 🚀 Funcionalidades

- **Operações Básicas**: Adição (`+`), Subtração (`-`), Multiplicação (`*`) e Divisão (`/`).
- **Cálculo de Porcentagem**: Suporte ao operador de porcentagem (`%`).
- **Limpar Tela (C)**: Zera a expressão atual do visor instantaneamente.
- **Visor Dinâmico**: Exibe a expressão em tempo real à medida que os botões são pressionados.

---

## 🛠️ Tecnologias Utilizadas

- **[Python 3]** — Linguagem de programação principal.
- **[Tkinter]** — Biblioteca nativa do Python para criação da interface gráfica (GUI).

---

## 📋 Pré-requisitos

Não é necessária a instalação de nenhuma biblioteca externa, pois o **Tkinter** já vem embutido por padrão no Python. Certifique-se apenas de ter o Python 3.x instalado em sua máquina.
