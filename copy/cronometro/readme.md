# ⏱️ Cronômetro em Python (Tkinter)

Uma aplicação desktop simples, moderna e funcional de cronômetro desenvolvida em Python utilizando a biblioteca gráfica nativa **Tkinter**. O projeto possui uma interface em estilo *Dark Mode* com suporte a redimensionamento de janela.

---

## 🚀 Funcionalidades

- **Iniciar**: Começa a contagem do tempo em tempo real (HH:MM:SS).
- **Pausar**: Interrompe a contagem mantendo o tempo atual no visor.
- **Resetar**: Zera a contagem e limpa o visor para "00:00:00".
- **Interface Responsiva**: Design moderno com tema escuro (*Dark Mode*), limites de redimensionamento e centralização dos componentes.

---

## 🛠️ Tecnologias Utilizadas

- **[Python 3]** — Linguagem principal do projeto.
- **[Tkinter]** — Biblioteca nativa do Python para construção de interfaces gráficas (GUI).

---

## 📋 Pré-requisitos

Por utilizar apenas recursos nativos do Python, **não é necessário instalar nenhuma biblioteca externa**. Você só precisa ter o Python 3.x instalado em sua máquina.
