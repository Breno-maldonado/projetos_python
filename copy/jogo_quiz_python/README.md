# 🧠 Quiz em Python

Este é um **projeto simples de quiz em Python**, desenvolvido com o objetivo de praticar lógica de programação, uso de condicionais e interação com o usuário via terminal.

O projeto faz parte do meu processo de aprendizado em Python, onde estou criando pequenos programas para consolidar os conceitos básicos da linguagem.

---

## 🎯 Objetivo do Projeto

Praticar os seguintes conceitos:

- Estruturas condicionais (`if / else`)
- Entrada de dados do usuário (`input`)
- Manipulação de strings (`lower`, `upper`)
- Criação de fluxos simples de perguntas e respostas
- Organização de projetos no GitHub

---

## 📌 Funcionalidades

- Exibição de perguntas no terminal
- Recebimento das respostas do usuário
- Validação das respostas
- Feedback imediato (resposta correta ou incorreta)
- Fluxo contínuo de perguntas

---

## ⚙️ Como Funciona

1. O programa apresenta uma pergunta ao usuário.
2. O usuário digita sua resposta.
3. O sistema compara a resposta informada com a resposta correta.
4. O resultado é exibido no terminal.
5. O fluxo segue para a próxima pergunta (ou finaliza o quiz).

---

## ▶️ Como Executar

1. Certifique-se de ter o **Python 3.8 ou superior** instalado.
2. Clone ou baixe este repositório.
3. No terminal, navegue até a pasta do projeto.
4. Execute o comando:

```bash
python quiz.py
