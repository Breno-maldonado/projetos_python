# Modern Login UI 🔐
Este é um projeto de interface gráfica (GUI) simples e moderna desenvolvida em Python, utilizando a biblioteca CustomTkinter. O sistema simula um painel de login com validação de credenciais e feedback visual para o usuário.

## ✨ Funcionalidades
- Interface Moderna: Utiliza o tema "Dark" para uma estética atual.

- Feedback em Tempo Real: Mensagens de sucesso (verde) ou erro (vermelho) aparecem diretamente na tela.

- Componentes Customizados: Botões e campos de entrada estilizados.

## 🚀 Tecnologias Utilizadas
- Python (Versão 3.x recomendada)

- CustomTkinter (Biblioteca para interfaces modernas)

## 🛠️ Como Instalar e Rodar
1. Clone o repositório:
``` git clone https://github.com/seu-usuario/nome-do-repositorio.git ```
2. Instale a biblioteca necessária: O customtkinter não vem instalado por padrão no Python. Instale via terminal:
``` pip install customtkinter ```
3. Execute o código:
``` python app.py ```
