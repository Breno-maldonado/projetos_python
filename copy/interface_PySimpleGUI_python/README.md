# 🖥️ Sistema de Login Moderno (PySimpleGUI)
Este projeto é uma interface gráfica de usuário (GUI) simples e moderna para um sistema de login, desenvolvida em Python utilizando a biblioteca PySimpleGUI. O foco principal foi criar um layout limpo, centralizado e com uma estética atualizada.

## 🚀 Funcionalidades
- Interface Moderna: Uso de fontes limpas (Segoe UI) e alinhamento centralizado.

- Design Customizado: Botão estilizado com cores personalizadas e sem bordas 3D antiquadas.

- Campos Inteligentes: Entrada de senha com caracteres ocultos (*).

- Validação de Dados: Sistema de verificação de usuário e senha com feedback visual via Popups.

- Layout Responsivo: Uso de VPush para garantir que os elementos fiquem centralizados verticalmente.

## 🛠️ Tecnologias Utilizadas
- Python 3.12+

- PySimpleGUI 5 (ou FreeSimpleGUI)

## 🔐 Credenciais de Acesso
Para testar a validação de sucesso, utilize os seguintes dados:

- Usuário: ``` admin ```

- Senha: ``` 0000 ```

## 📸 Demonstração do Layout
O layout foi estruturado com as seguintes características de design:

- Tema: Reddit (Fundo claro e limpo).

- Justificação: Centralizada (element_justification='center').

- Botão: Cor azul #0078D7 com texto em negrito.
