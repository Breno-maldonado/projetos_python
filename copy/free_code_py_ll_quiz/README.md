# 🎮 Python Quiz

Um jogo de perguntas e respostas dinâmico desenvolvido para praticar o controle de fluxo e a interação com o sistema operacional em scripts Python. 

## 💡 Evolução Técnica

Este projeto representa um avanço no estudo de lógica, implementando conceitos que tornam a interface via terminal mais profissional e robusta:

- **Loops de Repetição (`while`)**: Garantem que o usuário permaneça no desafio até encontrar a resposta correta, validando os dados em tempo real.
- **Biblioteca `os`**: Utilizada para limpar o console (`os.system("cls")`), proporcionando uma interface visual mais limpa e organizada.
- **Modularização**: Uso de funções específicas para renderizar menus e cabeçalhos ASCII, facilitando a manutenção do código.
- **Controle de Fluxo**: Decisões lógicas para permitir que o usuário escolha continuar ou sair do jogo após cada rodada.
