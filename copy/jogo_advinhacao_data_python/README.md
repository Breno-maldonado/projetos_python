# 🗓️ Jogo de Adivinhação de Datas

Este projeto é um jogo de adivinhação em Python onde o jogador deve descobrir uma **data secreta** (formato `DDMMAAAA`) a partir de uma dica fornecida.  
O jogador possui um número limitado de tentativas para acertar a data correta.

---

## 🎯 Objetivo do Jogo

Adivinhar corretamente a data oculta com base em uma dica textual, utilizando raciocínio lógico dentro do limite de tentativas.

---

## 📌 Funcionalidades

- Escolha aleatória de uma data a partir de um arquivo JSON
- Sistema de dicas associadas à data
- Validação de entrada do usuário
- Feedback visual com acertos e erros (✅ e ❌)
- Limite de tentativas
- Sistema de vitória e derrota

---

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- Bibliotecas padrão:
  - `json`
  - `random`
