# 🔐 Gerador de Senhas em Python

Este projeto é um **gerador de senhas aleatórias** desenvolvido em Python.  
Ele permite que o usuário escolha a **quantidade de caracteres da senha**, gerando combinações de letras, números e símbolos para aumentar a segurança.

---

## 📌 Funcionalidades

- Geração de senhas aleatórias
- Definição do tamanho da senha pelo usuário
- Uso de letras maiúsculas e minúsculas
- Inclusão de números
- Inclusão de caracteres especiais
- Validação da entrada do usuário

---

## ⚙️ Como Funciona

1. O usuário informa o **tamanho desejado da senha**.
2. O sistema valida se a entrada é válida.
3. O programa gera uma senha aleatória combinando:
   - Letras maiúsculas (`A-Z`)
   - Letras minúsculas (`a-z`)
   - Números (`0-9`)
   - Caracteres especiais (`!@#$%...`)
4. A senha gerada é exibida no terminal.

---

## ▶️ Como Executar

1. Certifique-se de ter o **Python 3.8 ou superior** instalado.
2. Clone ou baixe este repositório.
3. No terminal, navegue até a pasta do projeto.
4. Execute o comando:

```bash
python gerador_senha.py
