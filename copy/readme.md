# 🐍 Projetos Python

Este repositório reúne diferentes projetos desenvolvidos durante meus estudos de Python.

Os projetos armazenados nesta pasta foram desenvolvidos de forma **guiada**, com o objetivo principal de aprender e praticar os conceitos apresentados em cada projeto.

## 🎯 Objetivo

O objetivo desses projetos não foi necessariamente criar aplicações completas ou prontas para produção, mas sim utilizar cada projeto como uma oportunidade para:

- Aprender novos conceitos de Python;
- Praticar conceitos já estudados;
- Entender como diferentes funcionalidades podem ser aplicadas na prática;
- Desenvolver lógica de programação;
- Aprender a estruturar pequenos projetos;
- Identificar minhas dificuldades e pontos que precisam ser revisados;
- Ganhar experiência escrevendo e modificando código.
