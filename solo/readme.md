# 🐍 Projetos Python

Este repositório reúne projetos desenvolvidos de forma **independente durante meus estudos de Python**.

Diferente dos projetos guiados, aqui o objetivo é colocar em prática os conhecimentos adquiridos e tentar desenvolver soluções por conta própria, desde a ideia até a implementação.

## 🎯 Objetivo

O principal objetivo destes projetos é transformar conhecimento teórico em prática e desenvolver, gradualmente, minha capacidade de resolver problemas utilizando Python.

Através deles, busco:

- Desenvolver minha lógica de programação;
- Aplicar conceitos aprendidos anteriormente;
- Praticar a resolução de problemas sem seguir um passo a passo;
- Aprender a pesquisar e encontrar soluções por conta própria;
- Desenvolver projetos desde a concepção até a implementação;
- Identificar minhas dificuldades e pontos que precisam ser aprimorados;
- Ganhar cada vez mais autonomia na programação.

## 💡 Sobre os projetos

Cada pasta deste repositório representa um projeto desenvolvido de forma independente.

Os projetos podem variar bastante em complexidade. Alguns podem ser pequenos exercícios práticos, enquanto outros podem evoluir para aplicações mais completas.

Durante o desenvolvimento, nem sempre a solução será a mais eficiente ou a melhor possível. Isso faz parte do processo.

O mais importante é conseguir **pensar sobre o problema, tentar uma solução, pesquisar quando necessário, testar, corrigir erros e aprender com o processo**.

## 🚀 Evolução

Este repositório representa uma etapa importante da minha evolução como programador.

Conforme novos conhecimentos são adquiridos, novos projetos serão desenvolvidos e projetos antigos poderão ser revisitados para aplicar conceitos e melhorias aprendidos posteriormente.

> **Aqui, o objetivo não é mostrar projetos perfeitos, mas mostrar minha evolução em direção à autonomia como desenvolvedor.**
